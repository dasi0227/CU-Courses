FTEC5660 · ACE on Formula · Reproducibility

ACE stores experience in a text playbook, including formulas, solution methods, and common mistakes. Learning here means updating this playbook while keeping the model weights fixed.

During training, the Generator answers a question using the current playbook. The Reflector uses the answer, the reference answer, and feedback to identify useful lessons. The Curator organizes those lessons into entries and adds them to the playbook.

All three roles use the same model with different prompts. If an answer is wrong, the Generator can answer again using reflection, for up to three rounds, stopping early when correct. Later questions receive the updated playbook.

FTEC5660 · ACE on Formula · Reproducibility

Formula contains financial calculation questions covering 50 formula categories. I sample two training questions and one validation question per category, giving 100 training questions and 50 validation questions. I keep all 200 test questions.

The model is DeepSeek-V3.1-Terminus, with temperature zero, thinking disabled, and a maximum output of 4,096 tokens. Each group has three trials using the same samples and question order.

The original formulas and explanations are removed from the question input. Relevant formulas can still be supplied through the learned playbook. Accuracy is measured by comparing the numerical answer with the reference answer.

The three groups differ in the playbook supplied at test time. Group A answers directly with an empty playbook. Group B receives the full learned playbook. Group C uses JEV to select ten entries from the matching B trial's playbook for each question.

The bottom row shows the workflow. Each B trial starts with an empty playbook and processes the 100 training questions once. Every 20 steps, the current playbook is evaluated on the 50 validation questions.

The best validation playbook is then used for testing. C reuses that same playbook and does not train again, so the B-to-C comparison isolates the addition of filtering.

The left chart shows validation accuracy during B's training. The right chart shows the number of playbook entries at the same checkpoints. Each color represents one trial, and the stars mark the selected checkpoints.

The playbooks keep growing, but accuracy does not always rise. In trial one, accuracy drops from 82 percent at step 40 to 80 percent at step 60, before improving again. In trial three, steps 80 and 100 both reach 82 percent, even though more entries have been added.

FTEC5660 · ACE on Formula · Reproducibility

Group B supplies the full playbook for every question, including entries that may be irrelevant. My modification inserts JEV relevance scoring before the Generator answers.

JEV receives the question and candidate entries. The four criteria levels run from zero to three: unrelated; a general or topical reminder; useful for a supporting step; and directly useful for a core formula or key calculation.

The program ranks entries by score and selects the top ten. Ties keep the original order, and the selected entries are also passed to the Generator in their original playbook order.

JEV receives no reference answer and is asked only to assess relevance. The original playbook stays unchanged, and DeepSeek still produces the final answer.

The results lead to three conclusions. First, the learned playbook improves accuracy by 13.67 percentage points, supporting the main ACE finding.

Second, selecting relevant entries reduces combined testing cost by 61.92 percent compared with using the full playbook.

Third, C retains 80.50 percent accuracy, but it is slightly less accurate and slower than B. Full-playbook ACE gives the highest accuracy here; JEV filtering provides a lower-cost option. The choice depends on the accuracy and cost requirements.

There are three areas for further work, matching the rows on this page.

First, the model version, prompts, and reflection settings differ from the paper. Aligning these settings would allow a closer reproduction.

Second, the training and validation sets are small. Expanding them would help test whether the observed gains remain stable.

Third, I evaluate only fixed top-ten selection. Future work should compare other selection sizes, random selection, and keyword retrieval, choosing settings on the validation set. This would help distinguish the effect of keeping fewer entries from the quality of JEV's ranking.
