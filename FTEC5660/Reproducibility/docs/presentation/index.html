FTEC5660 · ACE on Formula

ACE improves the context given to a language model. It does not update the model's weights. The learned information is stored in a text playbook.

Three roles use the same model with different prompts. The Generator answers a question. The Reflector uses the answer and training feedback to identify useful lessons. The Curator turns those lessons into new playbook entries.

When an answer is wrong, the Generator can try again using reflection. Later questions receive the updated playbook, so experience from earlier questions can help them.

I use DeepSeek-V3.1-Terminus with temperature zero and thinking disabled. Each response allows up to 4,096 tokens.

The experiment uses 100 training questions, 50 validation questions, and all 200 test questions. These cover the same 50 formulas. I sample two training questions and one validation question for each formula.

All groups use the same samples and question order, and each group has three trials. The original formula and explanation are removed from the model input. Relevant formulas may still be learned through the playbook.

There are three groups. A answers the test questions with an empty playbook. B learns a playbook from the training questions. C reuses the best playbook from the matching B trial, but JEV selects ten entries for each test question.

For B, each trial starts from an empty playbook and processes the 100 training questions once. Incorrect answers allow up to three rounds of reflection and retry. Validation happens every twenty training steps. C does not repeat this training process.

FTEC5660 · ACE on Formula

My modification adds JEV before the Generator answers. JEV receives the question and the candidate playbook entries. It scores their relevance without receiving the correct answer or solving the question.

The criteria run from zero to three: unrelated, only generally related, useful for a supporting step, and directly useful for a core formula or key calculation.

I select the ten highest scores. Ties keep the original playbook order, and selected entries are presented in that order. The original playbook stays unchanged, and C requires no new training.

Filtering reduces accuracy from B's 82.83 percent to C's 80.50 percent. The average loss is 2.33 percentage points. The three paired trials lose five, one, and one percentage points.

At the same time, average DeepSeek token usage per test falls from 1.643 million to about 329,000, a reduction of 79.96 percent. JEV adds about 4.507 million tokens of its own usage.

The reduction in DeepSeek token usage is large, but JEV adds its own usage. We need to compare the combined model cost, not just DeepSeek tokens.

FTEC5660 · ACE on Formula

There are two main limitations. First, the sampled data and different model version prevent an exact comparison with the paper. A larger experiment with closer settings would provide stronger evidence.

Second, I test only a fixed top-ten strategy. There is no comparison with other selection sizes, random selection, or keyword retrieval. I cannot tell whether the accuracy loss mainly comes from keeping too few entries or from the relevance ranking.

Next, I would choose the selection size on the validation set, compare retrieval methods, and inspect missing or conflicting calculation rules.

The main finding is that a learned playbook helps this financial reasoning task. Full-playbook ACE gives the highest accuracy in my experiment.

JEV top-ten filtering keeps most of that accuracy gain while reducing the combined test cost. It also adds response time and slightly lowers accuracy, so it is a trade-off rather than a universal best choice.

These results show that both learning useful experience and selecting it carefully matter. The next step is to test how much context is needed to preserve accuracy. Thank you.
